# Phase 1 — Project Foundation

- Frontend and backend are independent deployable folders.
- Backend is a modular monolith with versioned REST endpoints.
- Environment variables are validated at startup.
- Security middleware includes Helmet, CORS, body-size limits and rate limiting.
- Errors use a consistent JSON response contract.
- Frontend uses React Router, TanStack Query, Axios and Tailwind CSS.
- Feature UI and business modules are intentionally deferred to later phases.
